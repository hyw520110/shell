## 🔧 详细说明

### install_ansible.sh - Ansible 安装脚本

**功能**: 自动安装 Ansible 自动化运维工具

**安装方式**:
```bash
./install_ansible.sh
```

**Ansible 特点**:
- 无代理架构
- 基于 SSH 通信
- YAML 配置文件
- 幂等性操作
- 丰富的模块生态

**适用场景**:
- 配置管理
- 应用部署
- 自动化运维
- 批量系统管理
