## 🔧 详细说明

### install-gh-proxy.sh - GitHub Proxy 安装脚本

**功能**: 安装 GitHub 加速代理服务

**代理内容**:
- GitHub 文件下载
- GitHub Release 资源
- GitHub Raw 文件
- GitHub API 请求

**加速方式**:
- 镜像站点
- CDN 加速
- 缓存优化
- 智能路由

**适用场景**:
- GitHub 仓库克隆
- Release 文件下载
- Raw 文件访问
- API 请求加速
