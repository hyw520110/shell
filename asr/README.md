# 语音识别

> 自动语音识别（ASR）工具的安装配置脚本

## 📋 目录说明

| 脚本文件 | 说明 | 版本检测 | 帮助函数 |
|---------|------|---------|---------|
| `install-funasr.sh` | FunASR 安装脚本 | ❌ | ❌ |
| `install-paddlespeech.sh` | PaddleSpeech 安装脚本 | ❌ | ❌ |

## 🚀 快速开始

### 安装 FunASR

```bash
cd asr
./install-funasr.sh
```

### 安装 PaddleSpeech

```bash
cd asr
./install-paddlespeech.sh
```

## 🔧 详细说明

### 1. FunASR - 阿里语音识别

**功能**: 开源工业级语音识别模型

**特点**:
- 高准确率
- 实时识别
- 多语言支持
- 轻量级部署

**支持模型**:
- 语音识别（ASR）
- 语音合成（TTS）
- 声纹识别
- 语音唤醒

**适用场景**:
- 会议记录
- 语音转写
- 智能客服
- 语音助手

### 2. PaddleSpeech - 百度语音工具

**功能**: 端到端语音处理工具包

**特点**:
- 丰富的模型库
- 易于使用
- 高性能
- 开源免费

**支持功能**:
- 语音识别
- 语音合成
- 声音克隆
- 语音分类

**适用场景**:
- 语音交互
- 音频处理
- 智能硬件
- 多模态应用
