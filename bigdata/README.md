# 大数据工具集

> 大数据处理、分析和机器学习工具的安装配置脚本

## 📋 目录说明

| 目录 | 说明 | 功能 |
|------|------|------|
| `ai-ml/` | AI/ML | 人工智能和机器学习工具 |
| `bi/` | BI | 商业智能工具 |
| `compute/` | 计算 | 分布式计算框架 |
| `datalake/` | 数据湖 | 数据湖解决方案 |
| `integration/` | 集成 | 数据集成工具 |
| `orchestration/` | 编排 | 工作流编排 |
| `query/` | 查询 | 查询引擎 |
| `warehouse/` | 数据仓库 | 数据仓库工具 |

## 🚀 快速开始

### 查看工具概览

```bash
cd bigdata
./bigdata-tools-overview.sh
```

## 🔧 详细说明

### 子目录功能

#### ai-ml/
**人工智能和机器学习**
- TensorFlow
- PyTorch
- Scikit-learn
- XGBoost

#### bi/
**商业智能**
- Apache Superset
- Metabase
- Redash
- Apache Zeppelin

#### compute/
**分布式计算**
- Apache Spark
- Apache Flink
- Hadoop MapReduce
- Ray

#### datalake/
**数据湖**
- Apache Hudi
- Delta Lake
- Apache Iceberg
- MinIO

#### integration/
**数据集成**
- Apache Kafka
- Apache NiFi
- Apache Sqoop
- DataX

#### orchestration/
**工作流编排**
- Apache Airflow
- DolphinScheduler
- Apache Oozie
- Luigi

#### query/
**查询引擎**
- Apache Hive
- Apache Doris
- Presto
- ClickHouse

#### warehouse/
**数据仓库**
- Apache Hive
- Apache Druid
- StarRocks
- Apache Kylin
