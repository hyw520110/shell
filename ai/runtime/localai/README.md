# LocalAI

> OpenAI compatible local inference runtime

## Layout

- `ai/conf/tools/runtime/localai.json`: AI Hub tool metadata
- `ai/runtime/localai/`: runtime-specific implementation area

## Current status

The runtime is managed through Homebrew from AI Hub:

```bash
brew install localai
local-ai --version
```

This directory is reserved for future LocalAI-specific scripts, templates, or wrappers.
