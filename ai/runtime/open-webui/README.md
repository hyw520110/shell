# Open WebUI

> Local Web UI runtime for OpenAI-compatible backends.

## Layout

- `ai/conf/tools/runtime/open-webui.json`: AI Hub tool metadata
- `ai/runtime/open-webui/install-open-webui.sh`: install and management script

## Usage

```bash
bash runtime/open-webui/install-open-webui.sh install
bash runtime/open-webui/install-open-webui.sh status
bash runtime/open-webui/install-open-webui.sh stop
```
