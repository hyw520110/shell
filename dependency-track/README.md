# Dependency Track

> 软件供应链漏洞监控和管理平台

## 📋 目录说明

| 目录 | 说明 |
|------|------|
| `bin/` | 二进制文件目录 |
| `conf/` | 配置文件目录 |
| `docker-compose.yml` | Docker 部署配置 |

## 🚀 快速开始

### 使用 Docker 部署

```bash
cd dependency-track
docker-compose up -d
```

## 🔧 详细说明

### 功能特性

**漏洞监控**:
- 依赖项漏洞扫描
- CVE 数据库同步
- 实时告警通知
- 漏洞修复建议

**SBOM 管理**:
- 软件物料清单生成
- 依赖关系分析
- 许可证合规检查
- 版本管理

**集成能力**:
- CI/CD 集成
- 多项目管理
- API 接口
- 权限管理

### 访问界面

- **Dependency Track 控制台**: http://localhost
- **默认用户**: admin
- **默认密码**: admin
