# Homebrew 管理脚本

本目录包含用于在 macOS 上一键安装、配置和管理 Homebrew 的脚本。

## 📂 文件说明

- `install-brew.sh`: 一键安装并自动配置 Homebrew 的脚本。

## 🚀 快速开始

### 安装 Homebrew

默认使用国内镜像源加速安装，并自动配置环境变量：

```bash
./brew/install-brew.sh
```

### 选项说明

| 选项 | 说明 |
|------|------|
| `-h`, `--help` | 显示帮助信息 |
| `--official` | 使用官方安装源（如果网络环境良好或已开启全局代理） |
| `--no-tools` | 安装完成后不自动安装常用工具（git, curl, wget, jq） |
| `--uninstall` | 卸载 Homebrew |

## ✨ 脚本特性

1. **镜像加速**: 默认集成国内优秀的镜像安装源，解决官方源下载缓慢或失败的问题。
2. **代理检测**: 自动检测本地常用代理端口（如 7890），并自动应用到安装会话。
3. **环境自动配置**: 自动识别 Apple Silicon (M1/M2/M3) 和 Intel 芯片，将 `brew shellenv` 写入对应的 Shell 配置文件（`.zshrc` 或 `.bash_profile`）。
4. **常用工具集**: 可选一键安装 `git`、`curl`、`wget`、`jq` 等基础开发工具。

## ⚠️ 注意事项

- 脚本仅支持 **macOS** 系统。
- 执行过程中可能需要输入系统开机密码以获取管理员权限。
- 如果使用的是国内镜像源，脚本会进入交互模式，请根据提示选择具体镜像提供商（推荐选择中科大或清华源）。
