# Viper 安全框架

> Viper 安全测试和漏洞利用框架

## 📋 目录说明

| 脚本文件 | 说明 | 版本检测 | 帮助函数 |
|---------|------|---------|---------|
| `viper-install.sh` | Viper 安装脚本 | ❌ | ❌ |
| `docker-compose.yml` | Docker 部署配置 | - | - |

## 🚀 快速开始

### 使用 Docker 部署

```bash
cd viper
docker-compose up -d
```

### 使用安装脚本

```bash
cd viper
./viper-install.sh
```
